# PAGA Atomic Lines Intake Equation R2

12 Nov 2026. PJ2608-0550 Official Working.

The existing 07 Vendor Offer record can carry ALIE R2 source atoms. The quote
register displays TAG status, quoted part or service, parent association,
native quantity/rate, source and the decimal rollup by class. Equipment feeds
A1, with C1 as its non-additive view. Services feed C7, tools C5, commissioning
spares C2 and other source costs E. C6 supports system or common consumables
and F supports insurance through the same class contract.

The INDUSTRONIC revision keeps all original Offers and their priced package
owners. Component and activation references have no separate amount. Cabinet
TAGs supported by the DTS at building level are distinguished from generated
PROV TAGs and unresolved intended assignments. The quoted package discount
stays on the supplier summary. ID-IE QO26163R1 and QO26169 use new source
records under the existing vendor identity. Source service rates, Thailand
mobilization and provisional Myanmar work quantities have separate evidence.
Unit-rate-only rows have an OPEN extension and retain the original rate.
Bangkok FAT is a quoted service-day package with unspecified staffing.

ADR-0550-001 principles 1, 2, 5, 6, 9, 10, 11 and 12 apply. The private
register augments exact source records, preserves consumed/deleted rows and
locally edited fields, and creates no commercial price selection or new module.
The existing Working and customer-issue process controls adoption of the
source data. The three private Atomic Lines JSON extracts mirror the registered
atoms. Supplier rates, source payload and evidence identifiers stay outside Git.

Validation includes source binding, exact decimal totals, missing amounts,
duplicate and orphan atom protections, edit/deletion preservation, receipt
idempotence, the Vendor register, supplier revision and bid regressions, and
the production build.
