## Governing architecture

The page is intentionally built around the controlled causal chain:

`Source/Evidence → Requirement → Constraint → Engineering Input → CAL/Study/RPT → Proof → Physical Object → Quantity Driver → MTO/Bulk → Work/Service → VDRL/QA → FAT/IFAT → Logistics/Regulatory → Site → SAT/Commissioning → Handover → Cost/Schedule/Risk → Release`

Hard controls:

- NO SOURCE != ZERO SCOPE
- NO FINAL QUANTITY != ZERO QUANTITY
- TBC != ZERO COST
- Vendor offered quantity != required quantity
- Selling rate != internal payroll cost
- One physical trip is counted once
- Shared/common cost is not divided equally by 19 systems
- 0553 provides methodology/calibration only; it is never a source of 0550 project facts
