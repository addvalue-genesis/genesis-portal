# PJ2608-0550 — Chat-to-Code Sync 2026-10-06 / 01

## Agreed team working rule

The project is developed collaboratively in chat, but material conclusions must not remain only in chat.

Controlled sequence:

`READ CURRENT JSX/STATE → READ SOURCE → ANALYZE/ENGINEER → AGREE → SYNC JSX/JS/JSON → VALIDATE → COMMIT`

A material conclusion that has not been synchronized into controlled code/state is not considered closed.

## Governing method

- First Principles
- Telecom Constraint-Based Engineering
- Parametric Cost Model

These are executable controls, not explanatory text only.

## Data architecture

The team works through React/JSX. MariaDB and JSON work together behind the UI:

- MariaDB: system of record, relationships, history/revision, actuals/calibration.
- JSON: API/snapshot/import-export/offline/team-readable state.
- GDrive/Excel/RFQ/vendor evidence: upstream source evidence.

Normal project work should not require the user to manage DB/JSON directly.
